일별 프리미엄: 같은 캘린더 날짜의 원주 종가와 DR 시장 종가로 계산합니다. 원주 장 마감 수 시간 후 DR 시장이 마감하므로, 이 수치는 "DR 시장이 원주 종가 대비 얼마나 앞서갔나"로 해석됩니다. 한쪽 시장 휴장일은 직전 거래일 종가를 이월해 계산하며 툴팁에 (이월)로 표시합니다.

계산 방식

프리미엄(%) = (DR 가격(USD) * 환율 / (원주 가격 * 전환비율 r) - 1) * 100
  • DR 가격: 예탁증서(ADR) 1주의 시장 가격 (USD)
  • 원주 가격: 현지 시장(HKEX) 원주 1주 가격 (HKD)
  • 환율: USD/HKD (USD 1달러당 HKD)
  • 전환비율 r: DR 1주가 대표하는 원주 수 = 8 (ADS 1주 = 보통주 8주)
  • 프리미엄 > 0 이면 DR가 원주보다 비쌉니다(프리미엄), < 0 이면 디스카운트입니다.

보조 지표

전일 대비(%p) = 오늘 프리미엄 - 직전 데이터 포인트 프리미엄 SMA_n(d) = 직전 n개 데이터 포인트(거래일 기준, d 포함) 프리미엄의 단순 평균 기간 평균 = 현재 화면에 표시 중인 구간의 프리미엄 단순 평균 주/월 단위 값 = 해당 주(ISO, 월-일)/캘린더 월의 마지막 거래일 값 주/월 단위 거래량 = 해당 기간 실거래일 거래량 합계

전환 현황 지표

DR 물량의 원주 환산: N_dr_local = N_dr * r 현재 전환율(%) = N_dr_local / N_total * 100 (DR 형태로 예탁된 비중) 한도 소진율(%) = N_dr_local / L * 100 (L = 전환한도, 확인 종목만) DR 시장 금액 = N_dr * P_dr (USD) 현지 시장 금액 = (N_total - N_dr_local) * P_local
  • N_dr: DR 발행 잔량(ADS 주 수), N_total: 원주 총발행주식수
  • SMA는 일 단위 시계열 기준으로 정의하며 주/월 단위 화면에서는 표시하지 않습니다.

본 정보는 투자 조언이 아니며, 데이터 오류·지연이 있을 수 있습니다.

본 사이트의 모든 정보는 참고용이며 투자 조언이 아닙니다. 데이터는 지연·종가 기반이며 정확성을 보장하지 않습니다.

본 사이트는 비상업 목적의 시험 운영 페이지입니다. 광고·제휴 등 수익 활동을 하지 않습니다.
