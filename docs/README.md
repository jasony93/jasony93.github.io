# docs — 문서 체계

모든 팀 산출물 문서는 여기에 저장된다. 파일명 규칙: `YYYY-MM-DD-<주제>.md`
같은 주제의 개정판은 새 파일을 만들지 않고 같은 파일을 갱신하며 상단 이력 표에 기록한다.

| 폴더 | 작성 팀 | 내용 | 템플릿 |
|---|---|---|---|
| `planning/` | 기획팀 | 시장 조사, 기능 요구사항 문서(PRD) | [planning/TEMPLATE.md](planning/TEMPLATE.md) |
| `development/` | 개발팀 | 설계 문서 (아키텍처, 도구, 실행 방법) | [development/TEMPLATE.md](development/TEMPLATE.md) |
| `testing/` | 테스트팀 | 테스트 리포트 (항목별 PASS/FAIL) | [testing/TEMPLATE.md](testing/TEMPLATE.md) |
| `marketing/` | 마케팅팀 | SEO·수요 조사·수익화 전략 | [marketing/TEMPLATE.md](marketing/TEMPLATE.md) |

프로젝트 전체 개요와 진행 현황: [PROJECT.md](PROJECT.md) (관리자가 관리)
