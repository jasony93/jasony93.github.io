### 1.3 목표

1. 대상 종목(3.0절)별 ADR/GDR 프리미엄·디스카운트를 정확한 수식(3.3절)으로 계산해
   보여준다.
2. 일별 시계열 차트로 프리미엄 추이를 제공한다. 메인 화면부터 차트 중심으로 구성한다.
3. 계산에 쓰인 원천값(ADR 가격, 원주 가격, 환율, 전환비율, 각 값의 기준 시점)을
   화면에 그대로 노출해 신뢰를 확보한다 (경쟁 서비스가 안 하는 부분).

## 2. 대상 사용자와 사용 시나리오

**대상 사용자**

- (주 타깃) SK하이닉스·삼성전자 등 한국 주식을 보유/관심 있는 한국 개인투자자 -
  "해외에서 내 주식이 얼마에 거래되나", "프리미엄이 벌어졌나 좁혀졌나"를 확인.
- 한국/대만 ADR에 투자하는 미국·해외 투자자 - ADR가 원주 대비 비싼지 판단.
- 차익거래·헤지 관점에서 괴리율 추이를 모니터링하는 준전문 투자자.

**핵심 시나리오**

1. 사용자가 사이트 접속 -> 메인의 종목별 차트 카드에서 현재 프리미엄 %와 최근 추이를
   일람 확인 (1초 내 파악). SK하이닉스, 삼성전자, TSMC가 최상단에 고정 노출된다.
2. SK하이닉스 카드 클릭 -> 현재 프리미엄, 계산 근거(4개 원천값+기준시점),
   기간별(1M/3M/6M/1Y/상장이후) 프리미엄 시계열 차트 확인.
3. 삼성전자 카드 클릭 -> 런던 GDR(SMSN) 기준 프리미엄과 "ADR가 아닌 GDR" 안내 확인.
   TSMC로 전환해 동일 정보 확인, 종목 간 프리미엄 비교.

### 3.1 화면 구성

1. **메인 화면 - 종목별 프리미엄 차트 카드 그리드 (차트 중심)**
   - 기존의 "목록 표 + 프리미엄 절대값 내림차순 정렬" 구성은 폐기하고, 종목별
     **미니 차트 카드** 그리드로 대체한다.
   - 각 카드 구성:
     - 기업명 + DR 티커. 삼성전자에는 "GDR(런던)" 배지 표시(다른 종목은 ADR).
     - 현재 프리미엄 % (큰 숫자, 소수점 2자리. 색상: 프리미엄 양수=빨강/음수=파랑 -
       국내 관례)
     - 최근 30일 프리미엄 미니 차트(스파크라인, 0% 기준선 표시)
     - DR 가격(USD)·원주 가격(현지통화) 축약 표기, 데이터 기준 시점
     - 카드 클릭 -> 해당 종목 상세 화면 이동
   - **노출 순서 (인기순 고정, 사용자 지정 2026-08-03)**:
     1) SK하이닉스 2) 삼성전자 3) TSMC 4) 나머지 종목.
     나머지 종목의 순서 기준(기획팀 제안): **원주 시가총액 내림차순 고정, 반기 1회
     재산정**. 초기 순서는 개발 착수 시점의 시가총액 조회로 확정한다. 예상 순서(추정,
     개발 시점 확정 필요): KB금융 -> 신한지주 -> POSCO홀딩스 -> 한국전력 ->
     SK텔레콤 -> 우리금융지주 -> KT -> LG디스플레이.
   - 레이아웃: 데스크톱 3열 / 태블릿 2열 / 모바일 1열 그리드. 표 형태 보기 옵션은
     2차 검토.
2. **종목 상세 화면**
   - 상단 카드: 현재 프리미엄 % (큰 숫자), 계산 근거 4개 값(DR 가격+시점,
     원주 가격+시점, 환율+시점, 전환비율) 명시.
   - 프리미엄 시계열 차트(일별): 기간 탭 1M / 3M / 6M / 1Y / MAX. 0% 기준선 표시.
     툴팁에 해당일 프리미엄 %와 원천값 표시.
   - 수식 안내 섹션: 3.3절 수식과 용어 설명(라이트 버전), "본 정보는 투자 조언이
     아님" 고지.
   - **삼성전자(GDR) 전용 표기**: "이 종목은 미국 ADR가 아닌 런던증권거래소(IOB)
     상장 글로벌 예탁증서(GDR)입니다. USD로 거래되며 프리미엄 계산 방식은 ADR와
     동일합니다." 1줄 안내를 상세 화면과 메인 카드 배지 툴팁에 표시.
3. **공통**
   - 반응형(모바일 우선 - 뉴스 유입 트래픽은 모바일 비중이 높을 것으로 추정),
     한/영 병기 가능한 구조(MVP는 한국어).
   - **다크모드 지원 (사용자 지시 2026-08-03)**:
     - 기본값: 시스템 설정(prefers-color-scheme)을 따른다.
     - 헤더에 라이트/다크 수동 전환 토글 제공. 수동 선택은 localStorage 등에 저장해
       재방문 시 유지한다.
     - 차트(축·격자·툴팁·스파크라인)와 프리미엄 색상(빨강/파랑)을 포함한 모든 UI가
       두 테마에서 가독성(충분한 명도 대비, WCAG AA 수준 권장)을 확보해야 한다.

### 3.2 입력 / 출력

- 입력: 종목 선택, 차트 기간 선택, 라이트/다크 테마 전환.
  (사용자 자유 입력 없음 - 폼/계정 없음)
- 출력: 프리미엄 %(소수점 2자리), 원천값 4종+기준시점, 일별 프리미엄 시계열.

### 3.3 계산 로직 (수식)

**정의**

- `P_dr` : 예탁증서(ADR 또는 GDR) 1주의 시장 가격 (USD)
- `P_local` : 원주 1주의 현지 시장 가격 (KRW 또는 TWD)
- `FX` : USD 1달러당 현지통화 환율 (USD/KRW 예: 1,385 KRW/USD, USD/TWD 예: 32.5 TWD/USD)
- `r` : 예탁증서 1주가 대표하는 원주 수 (3.0절 표)

**DR 이론가 (원주 가격을 DR 1주 등가로 환산한 USD 가치)**

```
DR_fair_USD = (P_local * r) / FX
```

**프리미엄**

```
Premium(%) = (P_dr / DR_fair_USD - 1) * 100
           = (P_dr * FX / (P_local * r) - 1) * 100
```

- Premium > 0 -> DR가 원주보다 비쌈(프리미엄), < 0 -> 디스카운트.
- **삼성전자 GDR에도 동일 수식을 그대로 적용한다**: P_dr 자리에 런던 GDR(SMSN)
  가격(USD), r=25, FX=USD/KRW. GDR가 USD로 표시·거래되므로 추가 통화 환산은 없다.

**검산 예 1 (SK하이닉스, 공모 시점 실측값)**: P_local = 2,186,000 KRW (2026-07-09
KRX 종가), r = 0.1, FX = 약 1,385 KRW/USD 가정 시
DR_fair = 2,186,000 * 0.1 / 1,385 = 약 $157.8.
공모가 $149 -> Premium = 약 -5.6%. (주의: 1,385원은 수식 검산용 예시 환율이다.
당일 실제 환율은 약 1,503원이었고 이 경우 프리미엄은 약 +2.47%로, 언론 보도의
"상장 직후 프리미엄 3%"와 부합한다. 이후 +51%까지 확대 - 1.1절 보도와 방향·규모
부합. 테스트 기준은 5절 참조.)

**검산 예 2 (삼성전자 GDR, 역방향 환산)**: SMSN $4,188 (2026-07-31 종가,
Yahoo Finance 조회값), r = 25, FX = 1,385 가정 시 원주 환산가
= 4,188 * 1,385 / 25 = 약 232,000원. 같은 날 KRX 종가와 비교해 프리미엄을 계산한다.
(테스트 시 당일 실제 원주 종가·환율 사용)

**역방향 표시(부가)**: 원주 등가 환산가 `P_local_implied = P_dr * FX / r` 를 상세
화면에 함께 표시 (예: "SKHY $168.49 -> 원주 환산 약 2,527,000원").

### 3.3.1 가격 기준 시점 문제 (거래시간 불일치)

거래시간 (현지시간): KRX 09:00-15:30 (KST), TWSE 09:00-13:30 (TST), 미국 정규장
09:30-16:00 (ET), 런던 LSE IOB 08:00-16:30 (런던 시간, 삼성전자 GDR).
**한국·대만 장과 미국 장은 겹치는 시간이 없다** (KST 기준 미국 정규장은
22:30/23:30-05:00/06:00). 런던 장도 한국 장 마감 이후(KST 기준 16:00/17:00 개장)
열린다. 따라서 "같은 순간의 두 가격"은 존재하지 않으며, 어떤 시점의 값을 쓰는지
정의하지 않으면 수치가 무의미해진다.

**규칙 A - 현재(라이브) 프리미엄**: 각 시장의 "가장 최근 체결가"를 사용한다.
- DR 시장(미국/런던) 장중: `P_dr` = 실시간/지연 시세, `P_local` = 당일(직전) 현지
  종가, `FX` = 실시간 환율.
- 현지(한국/대만) 장중: `P_local` = 실시간/지연 시세, `P_dr` = 직전 DR 시장
  종가(정규장), `FX` = 실시간 환율.
- 화면에 각 값의 기준 시점을 반드시 표기 (예: "원주: 8/1 KRX 종가",
  "ADR: 실시간(15분 지연)").
- MVP에서 실시간 시세 수급이 어려우면 지연/종가 기반으로 하되 라벨을 정확히 붙인다.

**규칙 B - 일별 히스토리(차트)**: 같은 **캘린더 날짜 D**(현지 기준)의
`현지 종가(D)` + `DR 시장 종가(D, 해당 시장 현지 날짜 기준)` + `환율(D의 일말
기준가)`로 계산한다.
- 시간 순서상 "현지 종가(D) -> 수 시간 후 DR 시장 종가(D)"이므로 (미국은 약 8~9시간
  후, 런던은 약 1~10시간 후), 이 프리미엄은 "DR 시장이 현지 종가 대비 얼마나
  앞서갔나"로 해석된다. 이 해석을 차트 하단에 명시한다.
- **휴장일 처리**: 한쪽 시장만 휴장인 날(한국 공휴일, 미국 공휴일, 대만 공휴일,
  영국 공휴일이 서로 다름)은 휴장 시장의 직전 거래일 종가를 이월(forward-fill)하여
  계산하되, 해당 데이터 포인트에 "이월가 사용" 플래그를 저장하고 툴팁에 표기한다.
  양쪽 모두 휴장이면 포인트 생략.
- DR 정규장 종가만 사용(시간외 제외).
