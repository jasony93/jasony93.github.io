## 이력

## 0. 조사 범위와 방법

- 대상: 직접 경쟁(SKHY/ADR 프리미엄), 인접(김치프리미엄 트래커 - 동일한 "두
  시장 가격차" 구조를 오래 다뤄온 영역), 야간 시세류(삼성 GDR 수요와 겹침),
  해외 일반 금융 데이터 사이트의 스프레드 UI 패턴.
- 방법: 가능한 한 실제 페이지를 조회(2026-08-05~06). 접근 실패는 4절에 기록하고
  검색 결과 기반 서술에는 **추정** 표시.
- 중복 회피: 마케팅팀 `docs/marketing/2026-08-03-adr-premium-marketing.md`
  1.4절은 유입 채널·수익 모델 관점이며, 본 문서는 화면·지표·도구 관점이다.
- **본 문서는 제안까지이며 기능을 확정하지 않는다** (2차 범위 재문의 원칙 유지).

## 3. 우리가 이미 우위인 부분 (차별점 유지 판단용)

조사 대상 어디에서도 확인되지 않은 우리만의 자산:

1. **멀티 종목 프리미엄 (11~12종)** - 경쟁 직접군은 전부 단일 종목(SKHY) 또는
   특정 자산군. 우리만 "한국 ADR 전체 + GDR + 대만 + 홍콩"을 한 곳에서 본다.
2. **장기 히스토리 + 기간 집계(일/주/월) + 패닝** - skhypremium은 최대 1Y,
   기간 탭만 제공. 우리는 MAX(최장 20년)와 집계 단위 전환·구간 탐색을 제공.
3. **전환 현황(한도·전환율·시장별 금액)과 전환 구조 시각화·자유도 배지** -
   조사한 어떤 사이트에도 없다. "왜 프리미엄이 유지/수렴하는가"에 답하는 유일한
   기능이며, 1차 출처 기반 데이터라는 점에서 모방 난이도도 높다.
4. **계산 근거 4종 + 기준 시점 라벨 + 이월 표기** - skhypremium이 방법론
   페이지로 수식을 공개하는 수준이나, 우리는 값별 기준 시점·휴장 이월까지
   화면에서 밝힌다.
5. **SMA·기간 평균·거래량 등락 색상** - 프리미엄 시계열에 기술 지표를 얹은
   사례는 조사 범위에서 확인되지 않았다(김프 사이트는 TradingView 위젯 의존).
6. **다크모드·접근성(WCAG 측정 이력)** - 김프 일부만 다크모드 보유.

시사점: 경쟁자는 **실시간성·언어·부가 콘텐츠**에서 앞서고, 우리는 **데이터
깊이·설명력·투명성**에서 앞선다. 실시간성 추격(C4)은 비용 대비 승산이 낮으므로,
깊이를 살리는 C1(비교 뷰)·C8(가이드)로 격차를 벌리는 편이 유리하다는 의견이다.
