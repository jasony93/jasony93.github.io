## 1. 손익구조 개선안

### 1.1 수익 측 - 기존 광고 모델의 최적화 여지

| 항목 | 내용 | 기대 효과(추정) |
|---|---|---|
| 콘텐츠 페이지 비중 확대 | 도구 페이지는 체류가 짧아 광고 단가가 낮다. 가이드/해설 페이지(기존 문서 2.5절)를 2~3편에서 8~10편으로 확대(종목별 해설, 전환 절차, 세금·수수료 비교 등). 금융 콘텐츠 니치는 RPM이 높다는 자료 다수( https://www.ranktracker.com/ko/blog/understanding-rpm-revenue-per-mille-in-adsense-what-it-means-and-how-to-optimize-it/ ) | 사이트 평균 RPM 상향. 콘텐츠 페이지 RPM은 도구 페이지의 2~5배 가능(추정) |
| 광고 배치 | 차트 시야를 가리는 앵커/전면 광고는 초기엔 지양(재방문 훼손). 상세 페이지 차트 하단 1개 + 가이드 본문 내 2개 수준에서 시작, 데이터(D6 분석 도구)로 조정 | 이탈률 방어와 단가의 균형 |
| 광고망 이원화 | 애드센스 기본 + 국내 트래픽에 카카오 애드핏 병행 테스트. 동시 노출이 아닌 지면 분리 A/B | 채우기율·단가 개선 소폭(추정) |
| 시즌성 활용 | 프리미엄 급변(뉴스 사이클) 시 트래픽 폭증 구간에 광고 수익이 집중된다 - 자동 갱신(D5)과 SNS 정기 게시로 급변일 유입을 놓치지 않는 운영 체계 | 수익의 변동성은 커지나 총량 증가 |

신규 수익원은 2절(BM 후보)에서 다루고 3절 시나리오에 반영한다.

### 1.2 비용 측 - 고정비 절감 (현 월 $32~105 -> 하한 약 $20대 목표)

고정비의 대부분은 상업 데이터 API다. PRD 3.4절 표를 근거로 "유료가 꼭 필요한
범위"를 다시 쪼갠다.

| 데이터 | 무료 공식 소스 후보 | 유료 필요 여부 판단 |
|---|---|---|
| KRX 원주 시세 (9종목+삼성전자 원주) | KRX 정보데이터시스템 Open API (공식·무료, data.krx.co.kr) | 상업 이용 조건 약관 확인 필요(PRD 기재). 허용 시 유료 불필요 |
| TWSE 원주 시세 (2330) | TWSE OpenAPI (공식·무료, openapi.twse.com.tw) | 상동 |
| USD/KRW·USD/TWD 환율 히스토리 | 한국은행 ECOS·수출입은행 API (공공·무료) | 공공데이터라 상업 허용 가능성 높음(추정, 약관 확인) |
| 미국 DR 시세 (SKHY 등 9~10종) | 공식 무료 소스 없음(추정 - 거래소 시세는 라이선스 자산) | **유료 필수.** 단 일별 EOD만 필요하므로 최저가 플랜으로 충분: EODHD 약 $19.99/월, Polygon $29/월, Twelve Data $29/월 등. 단 "표준 요금제=개인용" 조항(PRD 3.4절)이 있어 상업 표시 허용 여부를 플랜별로 서면 확인해야 하며, B2B 계약 요구 시 더 비쌀 수 있음(추정) |
| 런던 GDR (SMSN) | 없음. LSE 데이터 재배포는 유료 라이선스가 일반적(추정, PRD 6절-2) | **비용 리스크 최대 항목.** 커버리지 있는 API가 제한적이고 별도 과금 가능성 |

절감 시나리오:
- **조합 최적화(권고)**: KRX·TWSE·환율을 공식 무료 API로, 미국 DR만 유료 최저가
  플랜으로 -> 고정비 하한 **월 약 $20~35**(추정)로 축소 가능. 기존 하한 $32 대비
  소폭, 상한 $105 대비 크게 낮아진다. 관건은 (a) 무료 공식 API의 상업 이용 약관
  (b) 유료 플랜의 상업 표시 허용 - 두 가지 모두 서면 확인이 선행돼야 한다.
- **SMSN 분리 결정**: 삼성전자 GDR 커버 비용이 과도하면(예: LSE 라이선스로 월 수십
  달러 추가) 삼성전자 페이지를 "출시 보류"하고 10종목으로 런칭하는 옵션. 마케팅
  관점 비용: "삼성전자 GDR" 키워드(1군)를 포기 - 야간 시세 수요와 겹쳐 아깝지만,
  SKHY·TSM 축만으로도 런칭 가치는 충분(추정). 라이선스 견적 확인 후 결정할 사안.
- 파이프라인 구조상 소스 교체 비용이 낮다(수집부만 교체, 계산·웹은 그대로) -
  개발팀 설계 문서 2절의 분리 구조 덕분. 무료 소스 병행은 소스 3~4개 관리 부담이
  느는 단점이 있다(장애 지점 증가).
- 호스팅·빌드는 이미 최소(정적 호스팅 0원, GitHub Actions 무료 티어 내 - 추정).

### 1.3 리스크 측 - 뉴스 사이클 의존 완화

문제: SKHY 프리미엄이 수렴하면(차익거래 개시로 이미 축소 국면) 검색·화제성이
동반 급감할 수 있다.

| 장치 | 내용 | 효과 |
|---|---|---|
| 재방문 루틴화 | "매일 아침 프리미엄 확인" 습관을 만드는 것이 목표. 일 1회 이상 자동 갱신(D5)은 전제. 북마크 유도 문구, 홈화면 추가(PWA 수준까지는 불요) | 검색 의존도 하락 |
| 뉴스레터 (2절 BM-6) | 주간 "전 종목 프리미엄 요약 + 주간 변동 해설" - 트래픽이 식어도 구독자 자산은 남는다. 뉴스 사이클 리스크의 직접 헤지 | 소유 채널 확보 |
| 알림 (2절 BM-1 연계) | "프리미엄이 X% 돌파하면 알림"(텔레그램 봇/브라우저 푸시). 급변 시 사용자가 스스로 돌아오는 트리거. 2차 기능 - 기획팀 검토 대상 | 급변일 트래픽 회수 |
| 수요의 구조적 축으로 이동 | SKHY는 이벤트성이지만 TSMC 프리미엄은 수년째 구조적( https://www.bogleheads.org/forum/viewtopic.php?t=461211 ), 한국 은행주 ADR 디스카운트도 구조적( https://en.sedaily.com/finance/2026/07/07/korean-financial-holdings-adrs-trade-at-half-of-us-bank ). 영문 콘텐츠로 영어권 수요(뉴스 사이클 무관) 흡수 | 트래픽 바닥 형성 |
| 종목·기능 확장 (2차 범위 - 사용자 재문의 필수) | 대만 ADR 추가(UMC·ASE 등), 야간 시세 계열(삼성 GDR 실시간 환산 - yasun.gg·sonmul.co.kr가 검증한 수요), 회사 비전인 "금융 도구 모음"으로의 확장(김프 사이트들이 코인 수요로 그랬듯 도구 포트폴리오가 사이클을 상쇄) | 단일 이슈 의존 해소 |

## 2. 광고 외 BM 후보 평가

평가 기준: (1) 수익 잠재력 (2) 필요 트래픽 규모 (3) 구현에 필요한 것
(4) 제품 적합성. 등급은 상/중/하(정성 판단, 추정).

유사 사이트 실태 조사: 무료 금융 데이터 사이트의 일반 모델은 "광고 + 프리미엄
구독" 하이브리드다(TradingView 유료 $14.95~/월, Finviz Elite, stockanalysis.com
광고+구독 - https://www.stockbrokers.com/review/tools/finviz ,
https://stockanalysis.com/article/stock-research-websites/ ). TradingView는 무료
임베드 위젯(출처 표기 필수)을 성장 엔진으로 쓴다(
https://www.tradingview.com/widget/ ). 국내 김치프리미엄 사이트들(kimpga.com,
scolkg.com 등)은 배너 광고와 거래소 가입 레퍼럴 링크가 일반적 구성으로 관찰된다
(직접 계약 조건은 비공개 - 추정. https://kimpga.com/ , https://scolkg.com/ ).
김프 사이트의 "거래소 레퍼럴"을 주식판으로 옮기면 곧 "증권사 계좌개설 제휴"다.

### BM-1: 유료 구독 (프리미엄 알림·실시간 데이터·고급 지표)

- 수익 잠재력: 중 (구독 100명 x 월 3천~5천원 = 월 30~50만원 - 도달 난도 높음, 추정)
- 필요 트래픽: 상 (무료 사용자 풀 + 강한 재방문층 형성 후. 무료->유료 전환율
  1~2% 통설 기준 활성 사용자 수천 명 필요, 추정)
- 필요한 것: 계정·결제 인프라, 알림 시스템, 실시간/장중 데이터(더 비싼 API - 현
  일별 EOD 전제가 깨져 고정비 급증), 2차 기능 범위 논의(사용자 재문의 필수)
- 적합성: 장기에는 업계 표준 모델(TradingView·Finviz 전례). 현 단계엔 시기상조
- **우선순위: 하(현 단계) / 상(장기)**

### BM-2: 임베드 위젯 (블로그·언론용, 무료+출처 링크)

- 수익 잠재력: 직접 수익 하 (무료 배포 전제). 간접 효과 상 - 블로그·커뮤니티
  글에 위젯이 박히면 백링크+브랜드 노출 = SEO 자산 (TradingView 모델:
  https://www.tradingview.com/widget/ ). 유료 화이트라벨(로고 제거)은 장기 옵션
- 필요 트래픽: 무관 (오히려 트래픽을 만들어주는 성장 도구)
- 필요한 것: iframe/스크립트 임베드 페이지(종목 파라미터), 도메인 확정.
  **제약: 위젯이 제3자 사이트에 데이터를 표시하는 것은 원천 데이터의 재배포에
  해당할 가능성이 높다(추정).** 프리미엄 %(자체 계산값)만 표시하고 원천 시세
  (가격·환율)를 위젯에서 빼면 제약이 완화될 수 있으나(추정), 데이터 API 계약서의
  파생 데이터(derived data) 조항 확인이 선행돼야 한다
- 적합성: 상 (계산 근거 투명성이라는 우리 차별점이 인용 가치를 높임)
- **우선순위: 상 (수익원이 아닌 성장·SEO 장치로서. 계약 조항 확인 후 착수)**

### BM-3: 프리미엄 시계열 데이터 API·라이선싱 판매

- 수익 잠재력: 하~중 (수요자가 퀀트·리서치 소수. 건당 단가는 높을 수 있으나
  판매량 미미 예상, 추정)
- 필요 트래픽: 무관 (신뢰·실적 필요)
- 필요한 것: API 서버(현재 서버리스 정적 구조를 벗어남), 과금·키 관리, 그리고
  **원천 데이터 계약의 재배포·파생 데이터 조항 검토(BM-2와 동일 제약, 더 엄격).**
  자체 계산값이라도 원천 시세에서 직접 파생되므로 "재배포 아님"을 단정할 수 없다
- 적합성: 중 (데이터 자산 활용이나 법적 확인 부담 대비 수익 불확실)
- **우선순위: 하 (장기 검토만)**

### BM-4: 증권사 계좌개설 제휴/CPA (해외주식 특화)

- 수익 잠재력: 상 (방문자=주식 투자자로 타깃 완전 일치. 금융 CPA는 건당 단가가
  높은 편 - 국내 제휴 플랫폼 존재: https://leaderscpa.com/leaderscpa/m/sub/service.asp ,
  https://dbsense.kr/m/sub/camp/camp_cpa.html . 증권사 캠페인 유무·단가는 미확인)
- 필요 트래픽: 중 (월 1만 PV대부터 소액, 수만 PV부터 유의미 - 추정)
- 필요한 것: (a) 제휴 경로 - CPA 플랫폼 가입 또는 증권사 직접 제휴(직접 제휴는
  트래픽 실적 요구 예상, 추정) (b) 배너/링크 슬롯(D8) (c) **규제 검토 필수** -
  금소법상 금융상품 광고는 심의·표기 의무가 있고, 제휴 형태에 따라 "광고 대행"
  이슈가 있을 수 있다(추정). 증권사 제공 심의필 소재를 그대로 쓰는 방식이 안전
- 적합성: 상 (ADR 페이지 방문자에게 "해외주식 계좌" 제안은 맥락 일치. 콘텐츠
  기회: "ADR 살 수 있는 증권사·수수료 비교" 가이드 = 제휴 랜딩 겸 SEO 콘텐츠)
- **우선순위: 상 (2단계 - 트래픽 검증 후 즉시)**

### BM-5: 환전·송금 서비스 제휴

- 수익 잠재력: 하 (해외주식 투자자는 증권사 앱 안에서 환전하는 것이 일반적이라
  외부 환전 서비스와의 접점이 약함 - 추정)
- 적합성: 하. **우선순위: 하 (비권고)**

### BM-6: 뉴스레터 (주간 프리미엄 리포트 -> 스폰서/유료화)

- 수익 잠재력: 중 (성장 후). 국내 금융 뉴스레터 스폰서십은 검증된 모델 - 어피티는
  구독 70만의 종합 경제 미디어로 성장해 광고 비즈니스 운영(
  https://uppity.co.kr/business/ , http://www.openads.co.kr/content/contentDetail?contsId=6090 ),
  순살브리핑 등 개인 발행 금융 뉴스레터도 다수( https://soonsal.com/ ).
  단가는 비공개라 미확인 - 구독자 수천~만 단위에서 회당 수십만원 수준으로 추정
- 필요 트래픽: 하~중 (사이트 방문자를 구독자로 전환 - 소규모부터 시작 가능)
- 필요한 것: 구독 폼(사이트 내), 발송 도구(스티비 등 - 소규모 무료/저가 티어,

- 적합성: 상 (1.3절 뉴스 사이클 헤지와 겸용 - 수익 장치이자 리스크 완화 장치)
- **우선순위: 상 (1단계부터 구독자 축적 시작, 스폰서 수익은 2~3단계)**

### BM-7: B2B 데이터 제공 (언론사·리서치·핀테크)

- 수익 잠재력: 중 (건당 단가 높으나 영업 필요, 계약 소수)
- 필요 트래픽: 무관 (브랜드 신뢰 필요 - 언론 무료 인용(기존 문서 4.1절)이 선행
  단계. "출처: [사이트명]"이 기사에 실리기 시작하면 유료 제공 협상 여지)
- 필요한 것: BM-3와 동일한 인프라·계약 검토 + 영업 리소스
- 적합성: 중. **우선순위: 중 (무료 인용 유도는 즉시, 유료화는 장기)**

### BM-8: 사이트 단독 스폰서십/네이티브

- 수익 잠재력: 중 ("이 사이트는 OO증권이 후원합니다" 단독 스폰서 - 니치 사이트의
  검증된 모델이나 국내 사례 단가 미확인, 추정)
- 필요 트래픽: 상 (월 수만~수십만 PV + 타깃 순도 증명 필요, 추정)
- 필요한 것: 트래픽 실적 리포트, 직접 영업. 금소법 광고 규제는 BM-4와 동일
- 적합성: 상 (광고보다 UX 훼손이 적고 단가 높음)
- **우선순위: 중 (3단계 - 트래픽 실적 확보 후 제안 영업)**

### BM-9: 기부/후원 (Buy Me a Coffee 등)

- 수익 잠재력: 하 (미미, 추정). 비용·부작용 0
- **우선순위: 중 (구현 비용이 0이므로 1단계에 병행 - 기대치는 낮게)**

## 3. 개선 후 손익 시나리오 재추산 (전부 추정)

공통 가정: UV ~= PV/2.5, 페이지 RPM $2~5(광고), 환율 1달러=1,400원 어림.
CPA 가정: UV의 0.2~0.5%가 제휴 링크 클릭, 클릭의 5~10%가 계좌 개설, 건당
수수료 1~3만원(제휴 플랫폼 단가 미확인 - 전부 추정). 뉴스레터 전환: 방문 UV의
0.5~1%가 구독(추정).

### 시나리오 A - 비용 최적화 + 광고만 (1단계)

- 고정비: 월 $20~35 (1.2절 조합 최적화, SMSN 보류 여부에 따라 변동)
- 손익분기: RPM $5 -> 월 4,000~7,000 PV, RPM $2 -> 월 10,000~17,500 PV
- 기존 추산(6,400~52,500 PV) 대비 **손익분기가 절반 이하로 하락.** 뉴스 사이클
  트래픽만으로도 방어 가능성이 커진다(추정)

### 시나리오 B - A + 증권사 CPA (2단계, 월 3만 PV 가정)

- 수익: 광고 $60~150 + CPA: UV 12,000 x 0.2~0.5% 클릭 = 24~60클릭, x 5~10% 전환
  = 1~6건/월, x 1~3만원 = 월 1~18만원 (중간값 약 월 4~6만원 = $30~45)
- 합계 수익 약 $90~195/월 vs 비용 $20~35 -> **월 $55~175(약 8~25만원) 흑자**(추정)
- 민감도: CPA 성과는 배치·콘텐츠("증권사 비교" 가이드) 품질에 크게 좌우. 하한
  가정에서도 광고 단독 대비 수익 30~50% 증가(추정)

### 시나리오 C - B + 뉴스레터 스폰서 (3단계, 월 10만 PV·구독 8천 명 가정)

- 수익: 광고 $200~500 + CPA $100~150(트래픽 비례, 체감 증가 가정) + 뉴스레터
  스폰서 월 1~2회 x 회당 20~50만원(단가 비공개 - 구독 규모 기준 보수 추정)
  = 월 $140~700 상당
- 합계 약 $440~1,350/월 vs 비용 $20~35(+뉴스레터 발송비 소액) ->
  **월 60~185만원 수준 흑자**(추정)
- 단 월 10만 PV·구독 8천은 뉴스 사이클 재점화 또는 영문 확장 성공을 전제로 하는
  낙관 시나리오다. 도달 못 하면 B 수준에 머무름

요약: 비용 최적화(A)만으로 적자 리스크가 절반 이하로 줄고, CPA(B)가 붙으면 월
1만~3만 PV대에서 흑자 전환이 현실적이다(추정). C는 상방 시나리오. 모든 수치는
런칭 후 실측(D6)으로 갱신해야 한다.

## 4. 기획팀 검토 요청 사항

각 BM이 요구하는 제품 기능을 아래에 목록화한다. 기획팀은 (a) 구현 난이도·규모
(b) 2차 범위 정합성(부가 지표·확장은 사용자 재문의 필수 - PRD 4절) (c) 데이터
라이선스 영향 (d) MVP 구조(정적 사이트·서버리스)와의 충돌 여부를 평가해 달라.

| # | 기능 | 연관 BM | 검토 포인트 |
|---|---|---|---|
| P1 | 뉴스레터 구독 폼 + 주간 요약 자동 생성 파이프라인 | BM-6 | 정적 사이트에 폼 붙이는 방식(외부 폼 서비스 vs 자체), 파이프라인 데이터로 주간 리포트 템플릿 자동 생성 가능성, 개인정보 처리 |
| P2 | 프리미엄 임계값 알림 (텔레그램 봇 우선, 브라우저 푸시 차선) | BM-1, 1.3절 | 서버리스 유지 가능 여부(봇+cron으로 가능한지), 2차 범위 편입 여부 |
| P3 | 임베드 위젯 (종목 파라미터, 계산값만 표시 모드) | BM-2 | iframe vs 스크립트, 원천 시세 미표시 모드의 기술 타당성, 데이터 계약 파생 조항과의 정합(관리자·법무 확인과 병행) |
| P4 | 제휴 링크/배너 슬롯 + 증권사 비교 가이드 페이지 | BM-4 | 기존 D8(광고 슬롯)과 통합 설계 가능 여부, 심의필 소재 게재 방식 |
| P5 | 데이터 소스 조합 교체 (KRX·TWSE·ECOS 무료 공식 + 미국 유료 최저가) | 1.2절 | 파이프라인 수집부 교체 난이도, 소스 3~4개 병행의 장애 처리, SMSN 보류 시 구성 변경 범위 |
| P6 | 대만 종목 확장(UMC 등)·야간 시세 계열 기능 | 1.3절 | 2차 범위 후보로서 우선순위 평가 (사용자 재문의 전제) |
| P7 | (장기) 계정·결제·유료 구독 | BM-1 | 현 구조 대비 필요 인프라 규모 - 장기 로드맵 배치만 |
| P8 | (장기) 데이터 API 엔드포인트 | BM-3, BM-7 | 정적 구조 이탈 비용 - 장기 로드맵 배치만 |

마케팅팀 의견: P1·P4·P5가 손익 개선 직결(시나리오 A·B의 전제)이므로 우선 검토를
요청한다. P2·P3는 성장 장치로 그다음, P6~P8은 로드맵 배치만.
