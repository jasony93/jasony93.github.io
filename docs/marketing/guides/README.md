# 가이드 원고 형식 안내 (마케팅팀용)

이 폴더에 마크다운(.md) 원고를 넣으면 빌드 시 `/guide/<파일명>/` 페이지로
자동 생성된다 (`python src/build_pages.py`). 파일명이 URL 슬러그가 되므로
**영문 소문자와 하이픈만** 사용할 것 (예: `adr-premium.md` -> `/guide/adr-premium/`).

## 형식

파일 맨 위에 머리말 블록(필수), 그 아래 본문.
머리말은 아래 `---` 블록 형식 또는 HTML 주석 형식
(`<!-- title: ... meta_description: ... -->`, 2026-08-03 수신 원고 형식) 둘 다
지원한다. `meta_description`은 `description`과 같은 의미로 처리된다.
`slug`/`target_keywords` 키는 무시된다 (URL 슬러그는 파일명 기준).

```
---
title: ADR 프리미엄(괴리율)이란? 계산법과 해석
description: 수식·전환비율·환율·기준시점까지, ADR가 원주보다 비싸지는 이유와 계산법을 예시로 설명합니다.
---

## 첫 섹션 제목

본문 문단...
```

- `title`: 페이지 제목(title 태그·h1). 약 30자 내 권장 (마케팅 문서 2.3절).
- `description`: meta description. 약 80자 내 권장.

## 지원 문법 (최소 마크다운 부분집합)

- 제목: `##`, `###`, `####` (`# 제목`은 title과 중복이므로 생성 시 생략됨)
- 문단: 빈 줄로 구분
- 목록: `- 항목` (순서 없는), `1. 항목` (순서 있는)
- 강조: `**굵게**`, `*기울임*`, 인라인 코드: 백틱
- 링크: `[표시 텍스트](https://...)` 또는 본문에 URL을 그대로 쓰면 자동 링크
- 표: `| 셀 | 셀 |` 형식 (구분행 `|---|---|` 포함 시 첫 행이 머리행)
- 가로줄: `---` (단독 줄)
- 인용: `> 인용문`

이미지·각주 등 그 외 문법은 지원하지 않는다. 필요하면 개발팀에 요청할 것.

## FAQ 섹션 (선택 - 검색 리치결과용)

제목에 "FAQ" 또는 "자주 묻는"이 들어간 `##` 섹션 안의 Q&A가 FAQPage 구조화
데이터(JSON-LD)로 자동 변환된다 (마케팅 문서 2.4절). 두 형식 지원:
(1) `### 질문` 제목 + 답변 문단, (2) `**Q. 질문**` 문단 + `A. 답변` 문단.
FAQ 섹션이 없으면 FAQPage는 생성되지 않는다 (남용 방지 원칙).

```
## FAQ

### ADR 프리미엄이 뭔가요?

같은 회사 주식이 미국(예탁증서)과 현지(원주)에서 다른 가격에 거래될 때의
가격 차이 비율입니다.

### 왜 생기나요?

...
```

## 주의

- 매수/매도 판단을 유도하는 표현 금지 (마케팅 문서 2.5절-4). 페이지 하단에
  "투자 조언 아님" 고지가 자동 삽입된다.
- 원고 추가·수정 후 `python src/build_pages.py`를 실행해야 사이트에 반영된다.
