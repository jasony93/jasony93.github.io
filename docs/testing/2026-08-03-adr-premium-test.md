- 환경: Windows 11 Home, Python 3.11.9, yfinance 1.5.2, pandas 2.2.3, Chromium 계열 브라우저(뷰포트 강제 1280x800 / 768x1024 / 375x812, colorScheme 에뮬레이션)

  3. `python src/tests/verify_samples.py` (개발팀 실데이터 검증 재실행)

  5. `python docs/testing/scripts/2026-08-03-qa-triage.py` (1차 이상 항목 원인 규명)
