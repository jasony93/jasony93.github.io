# KSD "DR전환가능주식수량" 리트머스 테스트 결과

## 이력

| 날짜 | 내용 |
|---|---|
| 2026-08-05 | 최초 작성 (기획팀 설계 리트머스 테스트 실행 - 개발팀) |

## 0. 결론 (먼저)

**판정: (ii) 추가 전환 가능한 여유(headroom). 우리가 F7에서 필요한 DR 발행
잔량(N_dr)이 아니다. 따라서 tickers.json에 반영하지 않는다.**

기획팀이 설계한 리트머스(`docs/planning/2026-08-04-f7-data-sources.md` 2.1절)의
판정 기준 - "SKHY 값이 17,790,000 근처면 잔량, 0에 가까우면 여유" - 를 그대로
적용한 결과이며, **SKHY 신규 ADR의 값이 정확히 0**으로 나왔다.

## 1. 접근 경로 (인증키 없이 성공)

- 인증키가 필요한 공공데이터포털 API 대신 **동일 원천의 SEIBRO 모바일 웹**을
  HTTP 요청으로 직접 조회했다 (회원가입·활용신청 없이 접근 가능).
- 조회 경로:
  1. 종목 검색: `GET https://m.seibro.or.kr/common/selectIssueList.do?searchNm=<검색어>&searchCode=95`
     (searchCode 95 = 해외DR). 응답은 `ISIN:종목명|ISIN:종목명|...` 형식.
  2. 수량 조회: `POST https://m.seibro.or.kr/cnts/ovssec/selectOverSecDRConvPoss.do`
     with `searchCode=<ISIN>&txt_code=&txt_sch=<종목명>`
     (주의: ISIN이 `txt_code`가 아니라 **`searchCode`**로 들어간다 - 화면 JS의
     `selectOverSecDRConvPoss(code, name)` 함수 확인)
  3. 응답 HTML의 두 번째 테이블이 `일자 | DR전환가능주식수량(주)` 시계열.
- 세션 쿠키(WMONID, JSESSIONID)만 있으면 되고 별도 인증은 없다.
- 재현 스크립트는 본 문서 5절.

## 2. 리트머스 결과 (결정적 증거)

SEIBRO에는 SK하이닉스 DR ISIN이 **2건** 등록돼 있다.

| ISIN | 데이터 건수 | 최초 일자 | 최신 값 | 해석 |
|---|---|---|---|---|
| US78392B**2060** | **1건** | 2026/07/15 | **0** | **2026년 신규 ADR(SKHY)** - 상장(7/10) 직후 데이터가 처음 생겼고 값이 0 |
| US78392B**1070** | 1,265건 | **2010/03/31** | 130,921,524 | 상장 15년 전부터 존재 - 신규 SKHY가 아닌 **기존 DR 프로그램** |

**판정 근거 3가지**:

1. **신규 SKHY(2060)의 값이 0이다.** SEC 424B4 기준 발행 ADS는 177,900,000주
   (원주 17,790,000주)이므로, 이 필드가 "잔량"이라면 0일 수 없다. 반대로
   "추가 전환 여유"라면 **한도 전량 소진 상태와 정확히 일치**한다.
2. **1070의 데이터가 SKHY 상장 이전 1,254건 존재한다.** SK하이닉스가 2026-07-10
   이전에 이미 1.3억 주(총주식의 18.4%)를 DR로 발행하고 있었다는 뜻이 되므로
   "잔량" 해석은 성립하지 않는다.
3. **타 종목 값이 잔량으로는 불가능한 크기다** (아래 표). 우리금융지주는 값이
   총발행주식수의 **88.76%** - ADR 잔량일 수 없다. 반면 "아직 DR로 전환하지 않은
   여유"로 보면 자연스럽다.

### 2.2 시계열 방향 (보조 증거)

SKHY(1070)의 2026년 7~8월 시계열은 **증가** 추세다
(7/09 129,667,183 -> 8/05 130,921,524). ADR을 원주로 전환(소각)하면 재예탁
여유가 늘어나므로 **"여유" 해석과 방향이 일치**한다. "잔량"이라면 소각 시
감소해야 한다. (다만 이 종목은 신규 SKHY가 아니므로 보조 근거로만 취급한다.)

## 3. 상업 이용 약관 (공개 운영 전제로 확인)

- 공공데이터포털 "금융위원회_국제거래종목정보" 상세 페이지 확인 결과:
  - **이용허락범위: 공공저작물 제2유형 - "출처표시, 상업적 이용금지"**
  - 상업적 활용 시 **"한국예탁결제원과 사용 목적과 범위에 따른 정보이용계약이
    필요"**
  - 심의: 개발·운영 단계 모두 자동승인. 인증키(활용신청) 필요.
  - 출처: https://www.data.go.kr/tcs/dss/selectApiDataDetailView.do?publicDataPk=15059582
- SEIBRO 웹 화면 자체의 이용약관 문구는 모바일 페이지에서 노출되지 않았고
  ksd.or.kr 약관 페이지는 SPA라 본문을 확보하지 못했다(미확인).
- **시사점**: 설령 이 필드가 유용했더라도 **상업 사이트에는 계약 없이 표시할 수
  없다.** 1개월 비상업 실험 기간에도 출처표시가 필수이며, 상업 전환 시점에는
  KSD 계약이 선행돼야 한다. 이번에 반영하지 않기로 한 결정과 별개로 기록해 둔다.

## 4. 조치와 후속 과제

### 4.1 이번에 한 것 / 하지 않은 것

- **하지 않음**: tickers.json의 `dr_outstanding_manual` 계열 반영. 이 필드는
  N_dr이 아니므로 반영하면 전환율(cv)·시장별 금액이 전부 틀린다
  (부정확한 수치 표시 금지 원칙).
- **한 것**: SKHY 설정의 출처 메모(`_f7_refs`)에 "KSD 공식 데이터로 전환 여유
  0 확인(2026-07-15 기준)" 사실을 추가했다. 화면에 표시되는 수치는 변경 없음
  (기존 SEC 424B4 기반 값·라벨 유지).

### 4.2 부수 성과

- **SKHY의 "전환한도 전량 소진"이 공식 데이터로 확인됐다.** 지금까지 언론 보도
  기반이던 서술을 KSD 수치(신규 ADR 전환 여유 = 0)가 뒷받침한다. 현재 화면의
  `conversion_note`("한도 전량 소진으로 신규 절차 승인 전 불가") 근거가 강화됐다.
- SEIBRO 해외DR 종목 목록(24건)을 확보했다. 우리 10개 한국물 종목의 ISIN 매핑이
  가능해져, 향후 다른 KSD 화면(해외DR 발행종목 등)을 조회할 때 재사용할 수 있다.

### 4.3 남은 과제 (기획팀)

1. **N_dr(발행 잔량)은 여전히 미확보**다. KSD 경로는 이번 조사로 배제됐다.
   다음 후보: 예탁은행 공시(Citi/BNY 프로그램별 잔량), 20-F의 "as of" ADS 수량,
   상업 데이터 벤더.
2. "전환 여유" 지표 자체의 제품화 여부 - 화면에 "추가 전환 여유"를 별도 지표로
   보여줄 가치가 있는지 기획 판단 필요. 단 상업 라이선스(3절)가 선결 조건이다.
3. SEIBRO의 두 SKHY ISIN 중 어느 쪽이 나스닥 SKHY인지 1차 출처(예탁계약·SEC
   F-6) 대조 - 본 판정은 데이터 정황(상장일 대비 데이터 시작일)에 근거한 추론이다.

## 5. 재현 방법

조회 스크립트는 일회성 조사용이라 저장소에 커밋하지 않았다. 아래 최소 코드로
재현할 수 있다 (표준 라이브러리만 사용).

```python
import re, ssl, urllib.parse, urllib.request
BASE = "https://m.seibro.or.kr"
PAGE = "/cnts/ovssec/selectOverSecDRConvPoss.do"
ctx = ssl.create_default_context(); ctx.check_hostname = False
ctx.verify_mode = ssl.CERT_NONE
UA = {"User-Agent": "Mozilla/5.0", "Referer": BASE + PAGE,
      "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8"}
# 1) 세션 확보  2) ISIN을 searchCode로 POST
opener = urllib.request.build_opener(
    urllib.request.HTTPCookieProcessor(), urllib.request.HTTPSHandler(context=ctx))
opener.open(urllib.request.Request(BASE + PAGE, headers={"User-Agent": "Mozilla/5.0"}))
data = urllib.parse.urlencode({"searchCode": "US78392B2060", "txt_code": "",
                               "txt_sch": "에스케이하이닉스"}).encode()
html = opener.open(urllib.request.Request(BASE + PAGE, data=data, headers=UA)).read().decode()
rows = re.findall(r"<td[^>]*>(\d{4}/\d{2}/\d{2})</td>\s*<td[^>]*>([\d,]+)</td>", html)
print(rows[:5])
```

종목 검색: `GET /common/selectIssueList.do?searchNm=%&searchCode=95` (전체 목록).
